# CONTEXT — 外賣盈虧計算器

本詞彙表定義 KeeTa 外賣店盈虧計算使用的領域術語。兩代計算器共享同一套概念：

## 術語

- **每日帳本（Daily / keeta-profit-calculator.html）**：單日記帳。輸入當日實收與當日成本，月固定開支**÷30 攤銷到每一天**，輸出當日淨利。
- **月預測估算（Monthly forecast）**：前瞻性估算。輸入**每日平均**實收與成本、**營業天數**、**本月固定開支**，輸出**整月**營收、毛利、淨利、毛利率。
- **每日平均實收**（daily_avg_revenue）：預期每天的平均平台實收（已扣佣金配送優惠）。用戶手填，不是除出來的。
- **每日平均變動成本** = 每日平均食材 + 每日平均包裝。
- **營業天數**（operating_days）：本月實際營運天數（如 26 / 30）。手填。
- **月固定開支** = 月租金 + 月人工 + 月水電 + 月雜費。按月填一整月，**不做** ÷30（與每日版相反）。
- **月營收** = 每日平均實收 × 營業天數。
- **月毛利** = 月營收 − 每日平均變動成本 × 營業天數。
- **月淨利** = 月毛利 − 月固定開支。
- **月毛利率** = 月毛利 ÷ 月營收 × 100%。

## 換算方向對比（易混淆點）

| 概念 | 每日版 | 月版 |
|---|---|---|
| 固定開支 | 月 ÷30 → 每日 | 整月直接使用（不攤） |
| 變動成本 | 當日值 | 每日平均 × 天數 → 月 |
| 產出粒度 | 單日淨利 | 整月合計 |

## 歷史紀錄（History）

- **計算紀錄類型**（record.type）：`daily` | `monthly`，標記該條是日帳還是月預測。月紀錄的**月標籤**（monthLabel，如「2026年8月」）派生自 targetMonth 或當月日期。
- **計算時刻**（record.timestamp）：每次點「開始計算」時記錄的 ISO 時間，用於在歷史清單排序與顯示「幾筆於幾時」。
- **淨利**（record.netProfit）：該條最終盈虧數字，歷史清單直接顯示。
- **儲存媒介**：歷史清單存於瀏覽器 `localStorage`（key：`keetaHistory`），是一組 JSON 數組。純靜態頁無法寫回倉庫內的 JSON 檔，故歷史只在瀏覽器本地持久。
- 歷史紀錄與現有「目前輸入」快照（`keetaCalc`／`keetaMonthly`）是不同的事物：前者存每次計算的**結果快照**，後者只存 form 目前值。
